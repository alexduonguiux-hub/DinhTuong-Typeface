# Designer profile (Google Fonts)

Files for the designer page on fonts.google.com, in the layout of `catalog/designers/<name>/` in
[google/fonts](https://github.com/google/fonts): the onboarding team copies them there.

- `bio.html`: short biography (HTML paragraphs)
- `info.pb`: designer name (as in `AUTHORS.txt`), website, avatar file name
- `dizaistudio.png`: avatar, 200 x 200 px ("Đ" set in Dinh Tuong Bold)
